# 留一个问题 · 问题卡片

用于一起讨论的问题抽取组件，默认是盲盒。右上角可切换「卡片 / 盲盒」；两种模式共用题库和抽取进度。无外部字体、依赖、账号或 API Key。

Notion `/embed` 链接：<https://handeesome.github.io/notion-widgets/questions/?mode=box>。

## 本地预览

```powershell
cd questions
python -m http.server 4175
```

打开 `http://localhost:4175`。建议 Notion 嵌入尺寸为 **580 × 520 px**，窄屏也可使用；长问题需要增加嵌入高度或滚动。

## 抽取与编辑

- 盲盒分两步：点击「抽一个盲盒」抽出一个保持关闭的盒子，再**点击盒子本身**才播放约 0.6 秒的开盒动画并显示问题。等待或刷新都不会自动打开未开启的盒子；未开盒前不能再抽取。
- 卡片模式点击抽取即显示问题。切换模式不会换题；尚未打开的盒子切到卡片后，仍需点击「展开这张卡片」才显示。
- 同一轮不会重复。全部抽完并打开后，点击「开始新一轮」，多题时新一轮首题不会与上一题相同。
- 内置 12 个讨论问题作为示例。「编辑问题」默认用 `*` 遮住全部问题，只有点眼睛「显示问题」后才展示可编辑的文本；再次点击可隐藏，每次重新打开编辑器都会恢复遮挡。遮挡只用于避免提前看到题目，不是加密或访问控制。
- 显示后每行输入一个问题，再保存；空行会忽略、重复问题会合并。最多 500 题，每题不超过 500 字；保存会重新开始一轮。保持隐藏直接保存不会把星号当作题目。
- 「填入示例问题」只修改编辑框内容，保存后才生效；关闭或按 Esc 可取消编辑。
- 题库、当前问题、开盒状态、剩余题目、模式保存在当前浏览器的 `localStorage`。刷新会恢复；清理站点数据会重置。不支持存储时仍可抽取，但刷新后丢失修改和进度。
- **页面内编辑不会同步给其他人或其他设备**，Notion 嵌入和独立浏览器页面的存储也可能隔离。一起讨论时可由一人抽取并共享屏幕。

要让所有访问者默认使用你自己的题库，修改 [`questions.js`](./questions.js) 中的 `window.QUESTION_CARDS` 并重新部署。有本地自定义题库的浏览器仍优先使用自己的题库，可在编辑器中「填入示例问题」并保存，以使用部署后的默认题库。默认题库变更会重置使用默认题库的浏览器的抽取进度。

## URL 配置

默认跟随系统深浅色主题，首次进入为盲盒模式，之后记住选择。

| 参数 | 可选值 | 示例 |
| --- | --- | --- |
| `theme` | `light` / `dark` | `?theme=light` |
| `mode` | `card` / `box` | `?mode=box` |

例如 `https://handeesome.github.io/notion-widgets/questions/?theme=light&mode=box`。URL 中的模式是每次打开的初始值，进入页面后仍可切换。开启系统「减少动态效果」时会跳过动画，但仍需手动点击盒子开启。

## 部署与嵌入

将此目录作为静态网站部署，或随整个仓库一起部署，然后在 Notion 中输入 `/embed` 并粘贴组件的公开 HTTPS 地址，例如 `https://example.com/questions/`。需要同时发布 `index.html`、`styles.css`、`app.js` 和 `questions.js`。

默认题库随静态资源公开；本组件不提供多人同步、Notion 数据库连接或回答记录。

## 后续云端同步

当前发布的是可公开嵌入的静态基础版，**网页上线不代表浏览器数据已上云**。多台设备可访问同一网址和部署的默认题库，但页面内修改、开盒状态和抽取进度仍各自保存在本地。后续共享题库与进度同步需要接入数据库，并提供同一组题库的访问标识；本版尚未接入图库所用的 Supabase。

## 回归检查

在仓库根目录运行 `node --test questions/tests/widget.test.cjs`。若 Windows 沙箱阻止 Node 解析源文件路径，可使用 `Get-Content -Raw questions/tests/widget.test.cjs | node`。覆盖手动开盒、刷新后保持关闭、轮内不重复、模式切换、编辑器遮挡与保存、输入校验和存储不可用等情况，不连接外部服务。
