# Project Instructions

## README maintenance

- Every update to this project must include a review of the root `README.md` for accuracy.
- If a change affects behavior, setup, configuration, dependencies, directory structure, local preview, deployment, or usage, update the root `README.md` in the same change.
- When a change affects a specific widget, also review and update that widget's README (for example, `gallery/README.md` or `weather/README.md`).
- Do not consider project work complete until the relevant README documentation matches the implementation.
